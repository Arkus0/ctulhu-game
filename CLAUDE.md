# Instrucciones para Claude

Antes de modificar el proyecto, lee completos:

- `docs/DIRECCION-DE-DISENO.md`
- `docs/REFERENCIAS-LOCALES.md`
- `progress.md`
- el prompt de trabajo que corresponda dentro de `docs/`

## Referencias que no están en Git

El PDF original y el arte temporal son referencias locales deliberadamente excluidas del repositorio público. Una sesión abierta en la carpeta de trabajo completa puede encontrarlos en:

- `pdfcoffee.com_la-broma-macabra-5-pdf-free.pdf`
- `art/raw/*.png`
- `public/art/*.png`
- `art/contacto.png` y `art/ega_preview.png`
- `tools/crops.csv`

Comprueba que existen antes de afirmar que los has consultado. Si la sesión procede únicamente de un clon de GitHub, informa de que falta el paquete local de referencias. Puedes trabajar en código y diseño con los documentos versionados, pero no debes declarar fidelidad al módulo, comparar imágenes ni aprobar una sustitución artística sin disponer de las fuentes.

Nunca añadas a Git el PDF, páginas extraídas o ilustraciones derivadas. Los nuevos recursos solo se pueden versionar después de comprobar que son originales y documentar su procedencia y licencia.

## Criterio de adaptación

Usa el PDF para verificar hechos, cronología, personajes y tono; no para copiar texto extenso ni ilustraciones. El producto debe convertir el material en escenas, decisiones y consecuencias conforme a la dirección de diseño.
